Foundation · Layout General Set up the application shell once, then choose how each routed page uses the main area. good-app-layout owns the sidebar, topbar, and responsive navigation. Routed pages render inside its <router-outlet />. Each page then chooses Default view or Fill view. How the frame works On desktop, a 280 px sidebar sits beside the topbar and main area. At 900 px and below, the sidebar becomes a drawer. The shell handles offsets, navigation state, the drawer backdrop, and focus restoration. Group related links under expandable navigation items when the menu grows. 1. Define the root component Import GoodAppLayoutComponent and RouterOutlet. Give navigation items stable IDs and routes. The active route highlights its link and opens its parent group. 2. Compose the shell Place good-app-layout around the outlet. Supply your application's wordmark and symbol from public/brand/. Dark artwork is optional; without it, the light image is reused. mobileTopbarMenuMode="popup" keeps topbar links in a separate mobile menu. 3. Register the providers Register Angular Router and provideGoodUI() once. The Developing chapter covers package installation and styles. Choose the page behavior Continue with Default view for a normal scrolling page, or Fill view for a workspace with its own scroll areas.
