Getting started Introduction GoodUI is a complete Angular UI toolkit for SaaS applications. It comes with a reusable Penpot component library and is designed for AI-assisted design and implementation: component names, variants, and Angular APIs have a clear mapping, so the same building blocks can move from design to code. Layout flexibility is intentionally limited. GoodUI components own their spacing, structure, and composition rules so different combinations produce a consistent interface with little custom layout work. The toolkit includes an application shell, navigation, menus, controls, and page content components. The Angular package uses Tailwind CSS 4; homepage/ shows it in use.
