Start with the reusable GoodUI components in Penpot. Compose screens from the application shell, navigation, cards, menus, and controls; choose the published variants and use shared design tokens for light and dark themes. When working with AI, ask it to use GoodUI component names and variants in the design. The component map connects each published Penpot family to its Angular selector, inputs, and states. That gives designers and developers the same vocabulary and makes a design straightforward to implement as a useful frontend. Keep the Penpot component instances linked, then check responsive behavior, interaction states, and accessibility in the Angular implementation. Read the design-to-code guide.
