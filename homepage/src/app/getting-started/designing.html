Getting started Designing with GoodUI and an AI agent Build your interface with an AI agent and GoodUI. Start with a Penpot design, or give the agent wireframes or mockups to implement directly with the GoodUI Angular library. Designing in Penpot is optional. You can give your agent wireframes or mockups and ask it to build the interface directly with GoodUI. See Developing with AI to get started with that approach. Choose Penpot if you would like an editable UI design to explore ideas and plan your own extensions. You can also create that design later, after the application is already taking shape. The steps below explain the Penpot workflow if you choose it. For the Penpot workflow, start with a local project folder, the GoodUI skill, and an empty Penpot design file. Add the GoodUI library, connect your agent, and describe the screen you want. You can turn the design into an Angular application later. 1. Install the GoodUI skill from GitHub Create an empty local folder for your project and open it in your editor. Open a terminal in that folder and run these two commands to install the skill for Codex. You do not need Angular or npm to start designing. For Claude Code, replace .agents with .claude in both commands. Start a new agent session in this folder after installation. The skill tells the agent how to use GoodUI and where to find its references on GitHub. 2. Open a new Penpot project and add GoodUI Open Penpot, create a project, and create a design file inside it. Give the file your application's name. This is where the agent will create your screens. In the design file, open Assets, open the library manager, and add the shared GoodUI library. Its components are now available in your file. The GoodUI library file must be shared as a library in your Penpot team; if it is missing from the list, ask your workspace owner to give you access and share it first. Installing the skill does not install the Penpot library. 3. Connect your agent to Penpot Set up the Penpot MCP connection in your agent if you have not already connected it. Keep your new design file open and give the agent its link and the GoodUI library file's link. The skill supplies the instructions; the MCP connection lets the agent inspect and edit your actual design. Start with this short connection check. If something is missing, the agent should explain the required connection or access before creating a design. 4. Describe your first screen Tell the agent what you want to build. Describe who will use the screen, what they should see, and what they should be able to do. For example, paste this prompt and adapt the content to your application. Review the result in Penpot and ask for small changes in plain language: “Make the main action easier to find,” “Add an empty state,” or “Show me the mobile version.” The agent should reuse linked GoodUI components and their variants so your screens stay consistent. 5. Turn the design into an application when you are ready Your Penpot design is the starting point for implementation. Follow Developing to install the GoodUI Angular package, then use Developing with AI to have the agent implement your screen with the matching components.
