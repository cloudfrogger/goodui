Render a scrolling page layout="page" is the default. MainView adds page padding and lets the content scroll. Put every top-level content block in a direct good-section to align the heading and content to one centered reading width. Use the available width Direct Sections make a centered reading page, as shown above. For a scrolling page that uses the available width, put the content directly inside MainView. Its heading and content then start at the same left edge. The layout="page" value can be omitted because it is the default. For a workspace that meets all four edges without page scrolling, use the fill option described below. Fill option: use the entire client content area Fill is a variant of the same layout. Set layout="fill" on MainView to remove its outer padding and use the full width and height available to page content. The sidebar and topbar stay in place. The calendar below touches the edges of that remaining client area, without the page layout's surrounding whitespace. Place one primary workspace directly inside MainView. For Calendar, [fillHeight]="true" makes the calendar fill MainView and keeps its time grid, month view, and list scrolling within the component.
