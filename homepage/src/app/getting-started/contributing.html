Getting started Contributing Every contribution is welcome. Help us build a more complete toolkit for people and AI agents. You are welcome here GoodUI welcomes everyone who wants to help with its development. Experienced contributors, beginners, and AI enthusiasts all have a place here. Your first pull request is just as welcome as a larger contribution. We are happy to receive pull requests and appreciate the time people put into improving the project. A small fix, a clearer explanation, or a useful example can make GoodUI easier for the next person to use. Ways to help Help build and refine reusable components, improve desktop and mobile behavior, fix bugs, or make interactions more accessible. Documentation, Penpot designs, examples, localization, and agent skills are equally valuable areas to contribute to. The shared goal is a complete component toolkit that produces consistent interfaces with little application-specific styling. Extensions should fit that goal and remain useful across different products. We will review software extensions that fit GoodUI and its goals promptly. Send a pull request The source code is available in the GoodUI repository on GitHub. You can explore the issues for something to work on or bring your own idea. Read the contributor instructions, make your change on a branch, and open a pull request. Explain the problem or use case, what you changed, and how you checked it. For a visual change, include screenshots that show the result on desktop and mobile. Keep the Penpot design, Angular implementation, examples, and component references aligned when your change affects them. A focused contribution with clear context makes it easier for us to review and help it move forward. Build with AI, too AI-assisted contributions are welcome. Follow Developing with AI to set up the GoodUI skill and matching references, then use them to explore a change, improve an example, or build a component. Tell us what you wanted to achieve and what you verified. We are glad to have help developing GoodUI and making it a natural tool for the next generation of coding agents.
