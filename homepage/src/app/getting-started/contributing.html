Getting started Contributing Shape the components, design system, and agent tools that make up GoodUI. Experienced developers, beginners, and AI enthusiasts are welcome to help develop GoodUI. Bring your ideas, explore the code, and turn a useful improvement into a pull request. Ways to contribute Build and refine reusable components, improve desktop and mobile behavior, fix bugs, or make interactions more accessible. Documentation, Penpot designs, examples, localization, and agent skills are equally valuable areas to contribute to. Use GoodUI in your own project and share what you build. With your permission, we can link to your project in the GoodUI showcase, giving others a practical example of what they can create with the toolkit. Send us the project URL and let us know that we may feature it. The shared goal is a complete component toolkit that produces consistent interfaces with little application-specific styling. Extensions should fit that goal and remain useful across different products. We will review software extensions that fit GoodUI and its goals promptly. Send a pull request The source code is available in the GoodUI repository on GitHub. You can explore the issues for something to work on or bring your own idea. Read the contributor instructions, make your change on a branch, and open a pull request. Explain the problem or use case, what you changed, and how you checked it. For a visual change, include screenshots that show the result on desktop and mobile. Keep the Penpot design, Angular implementation, examples, and component references aligned when your change affects them. A focused contribution with clear context makes it easier for us to review and help it move forward. Build with AI, too AI-assisted development is part of GoodUI’s workflow. Follow Developing with AI to set up the GoodUI skill and matching references, then use them to explore a change, improve an example, or build a component. Describe the intended result and what you verified, including when an agent helped with the implementation. Clear context and checked results give reviewers a solid basis for the next step.
