Customize colors in your app Penpot color.* roles become CSS --good-color-* variables. The shorter --good-brand style aliases and Tailwind --color-good-* mappings use those roles. Brand and accent share the default light blue but serve different purposes; accent becomes lighter in dark mode. Overlay opacity is controlled separately by the component using it. Import GoodUI's stylesheet into your application's global stylesheet, then override the --good-color-* variables after the import. Add dark-mode overrides under [data-theme="dark"]. Component colors that use those roles follow automatically; explicit component colors, such as the primary Button hover color, can be overridden separately. GoodThemeService selects the appearance. It uses a saved choice first and the system preference when there is no saved choice. Calling setTheme stores the new choice. Keep Penpot and code aligned App-level CSS overrides change the running app only. To publish a shared GoodUI palette, change the matching tokens in Penpot, export the token JSON to design-tokens/penpot.tokens.json, then regenerate the CSS and verify the homepage. The export is a manual step; there is no live synchronization.
