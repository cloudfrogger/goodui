Getting started Developing Get started with developing using GoodUI in Angular. Install and style GoodUI GoodUI targets Angular 21.2. You need Node.js 20.19 or newer. Create an Angular app and install GoodUI from npm: Add the compiled GoodUI stylesheet to src/styles.css: Avoid flickering on page load A dark-themed app can briefly flash white while its stylesheets and JavaScript load. Setting data-theme="dark" alone still leaves the background white until the theme CSS arrives. The inline styles below immediately give the page a matching light or dark background. In your app's src/index.html, paste the entire snippet immediately after <meta charset="utf-8"> in the <head>, before external stylesheets and scripts. The script uses light or dark from the goodui-theme cookie. If the cookie is missing or has another value, it follows the system preference. If your app overrides GoodUI's color.canvas token, use your light and dark canvas colors in the inline styles as well. Initialize GoodUI services Add provideGoodUI() once to your root app.config.ts, alongside Angular Router. This is the shared provider entry point for GoodUI services, including notifications, calendar events, and theme handling. Components and services can then use Angular's inject() normally. The notification service is GoodNotificationCenter. Its publish() method accepts persist: false for a toast that must not enter notification history. You can turn history off by default in the provider options: A message's own persist value takes precedence. Inbox-only messages always appear in the panel. GoodUI's compiled CSS works without Tailwind in the consuming app. Add your application branding Pass your own wordmarks to the desktop sidebar and mobile drawer. Add GoodUI to an existing Angular app In your Angular 21.2 project, run npm install @cloudfrogger/goodui, add the same CSS import to its global stylesheet, and import GoodAppLayoutComponent and GoodMainViewComponent in the component that owns your page. Add provideGoodUI() to your existing root providers and keep provideRouter(routes).
