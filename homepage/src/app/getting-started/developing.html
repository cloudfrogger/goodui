The --routing option creates the router configuration required by good-app-layout. Start the app with npm start and open http://localhost:4200/. GoodUI's compiled CSS works without Tailwind in the consuming app.

Build GoodUI with the first four commands above. In your Angular 21.2 project, run npm install /path/to/goodui/angular/dist/goodui, add the same CSS import to its global stylesheet, and import GoodAppLayoutComponent and GoodMainViewComponent in the component that owns your page.

Ensure the app provides Angular Router, for example with provideRouter(routes) in app.config.ts. Use the page example above as a starting point; existing routes can render inside the layout with <router-outlet />.
