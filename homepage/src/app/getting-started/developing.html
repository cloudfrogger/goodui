Add provideGoodUI() once to your root app.config.ts, alongside Angular Router. This is the shared provider entry point for GoodUI services, including notifications and theme handling. Components and services can then use Angular's inject() normally.

The notification service is GoodNotificationCenter. Its publish() method accepts persist: false for a toast that must not enter notification history. You can turn history off by default in the provider options:

A message's own persist value takes precedence. Inbox-only messages always appear in the panel.

The --routing option creates the router configuration required by good-app-layout. Start the app with npm start and open http://localhost:4200/. GoodUI's compiled CSS works without Tailwind in the consuming app.

Build GoodUI with the first four commands above. In your Angular 21.2 project, run npm install /path/to/goodui/angular/dist/goodui, add the same CSS import to its global stylesheet, and import GoodAppLayoutComponent and GoodMainViewComponent in the component that owns your page.

Add provideGoodUI() to your existing root providers and keep provideRouter(routes). Use the page example above as a starting point; existing routes can render inside the layout with <router-outlet />.
