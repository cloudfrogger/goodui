Space mixed page content

Use good-section spacing="content" for explanations, images, examples, and code. It keeps headings close to their text and gives new topics more room. The default mode keeps compact layouts unchanged.

Detail lists

Use good-detail-list for compact label/value pairs in summaries, settings, and price breakdowns. It keeps the labels on the left and the values aligned on the right, even in a narrow panel.

Each div goodDetailRow contains one native dt for the label and one dd for the value. Add rows with ordinary Angular template control flow. The list has no inputs or outputs; its content is yours. The list spaces its rows. Put it inside good-prose when it sits beside a heading, text, or a form control; the parent then owns the spacing around the list.
