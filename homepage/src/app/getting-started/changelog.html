Getting started Changelog Notable changes to GoodUI components, behavior, and public examples. Entries describe changes that affect people using GoodUI. Each links to the commit that introduced the change. November 28, 2026 Softer dark appearance. Replaced near-black canvas and near-white body text with anthracite surfaces and soft gray text. Neutral selected, hover, border, and Badge roles follow the same palette. A release check guards 64 dark text pairs at 4.5:1 or higher. The Color Scheme chapter explains contrast thresholds, color-independent meaning, and verification limits. aa5a13a ISO/IEC 40500 framework review. Added a searchable table of all 86 WCAG 2.2 criteria for ISO/IEC 40500:2025, with OK or Not okay support labels and explanations on selection. Each row distinguishes bounded support, known gaps, unverified behavior, and application responsibilities; this is not a certification. The earlier WCAG 2.0 baseline is identified separately. Canonical assessment data and agent references are included. aa5a13a Filled Table workspaces. Tables can fill a bounded MainView with [fillHeight]="true". Header controls and pagination stay fixed while rows scroll beneath sticky column headings. Loading and empty states use the available height. The Table workspace example includes responsive commands and complete source. 01f4f77 Consistent page rhythm. MainView aligns headings and content with 32 px padding, reduced to 16 px horizontally at viewport widths of 640 px and below. Page and fill layouts share the same inset. Compact headings use weight 600, descriptions use muted 14 px text, and a 24 px gap separates the title block from content. Penpot, migration guidance, and agent references follow the same layout. 01f4f77 Responsive table header commands. Tables place compact search beside header actions. Project ActionBar with goodTableActions and appearance="compact" to move secondary commands into More as the available container narrows. Visible buttons and menu items share command IDs and disabled states. Matching Penpot compositions, discoverable agent guidance, and a compiled application example are included. b30ef70 November 26, 2026 Persistent Sidebar footer. Added optional good-sidebar-footer for settings links, workspace selectors, and other projected controls. The footer stays at the bottom while navigation scrolls above it, and retains its state in the mobile drawer. The Sidebar chapter includes examples; matching Penpot compositions and agent guidance are included. d5e01b0 November 25, 2026 Currency input. Added CurrencyInput with localized decimal entry, stable typing and caret position, and formatting on blur. Angular Forms and two-way binding use exact integer minor units; currency precision, required fields, bounds, readonly and disabled states are supported. Matching Penpot variants, examples, and agent guidance are included. Input also accepts a native keyboard hint through inputMode. 8be389a November 24, 2026 Record layouts and table actions. The Patient records example demonstrates readable details, edit drafts, separate telephone numbers, activity filters, and local documents using only GoodUI. Added Avatar, actionable EmptyState, responsive DetailList grids, contrast Cards, and a MainView identity slot. Tables accept projected title-row actions and custom empty templates. Matching Penpot compositions, guides, and agent references are included. de5384d November 22, 2026 Settings pages and responsive editing. The Settings example demonstrates overview, read mode, draft editing, validation, and archive confirmation. Sections provide titles, descriptions, local actions, and a quiet danger appearance. Tables support independent frame and density settings and external search; FormRow accepts removal actions alongside repeated fields. MainView places page actions below the full-width heading on mobile. dfe37ad Two-state theme selector. The Header theme toggle switches directly between Light and Dark and shows the currently active theme, including when it follows the device setting. The avatar's Dark Mode switch uses the same resolved state. GoodThemeService.cycle() now performs the same direct switch as toggle(); setTheme('system') remains available to restore automatic appearance. Penpot, examples, and agent references use the two-state selector. 8a17be7 Declarative application shell (breaking). Use good-app-shell with projected good-sidebar and good-app-header regions instead of AppLayout and its navigation arrays. Compose HeaderMenu and HeaderActions inside AppHeader; the former Topbar menu components now use Header names. Sidebar items follow the active route and keep their state when switching between the desktop column and mobile drawer. See Default shell, Sidebar, and Header menu for composition examples. 2b05ded Shared heading scale (breaking). Native h1 through h6 now match their GoodUI heading components, using a 28–16 px scale. Heading 7 exposes accessible level-seven semantics. Migrate former numbered headings 3–7 down one number to retain their HTML hierarchy. The Typography chapter shows both forms, and Penpot page 43 Typography Reference provides linked examples. 040e884 Explicit headings and projected page titles (breaking). Use good-heading-1 through good-heading-6 instead of the former Heading/Subheading selectors and level input. MainView now receives its title, summary, and optional eyebrow as projected components; its text inputs are removed. All homepage views and agent examples use the new composition. See Typography for the seven styles and migration examples. b6fec7a Header search shortcut. Enable [hotkey]="true" on good-header-search for a wide search trigger and Ctrl+K / Command+K support. Smaller screens retain a compact icon with the shortcut active. See Header actions for the working example. 54c26c6 Content spacing.
