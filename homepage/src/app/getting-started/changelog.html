Getting started Changelog Notable changes to GoodUI components, behavior, and public examples. Entries describe changes that affect people using GoodUI. Each links to the commit that introduced the change. November 3, 2026 World maps. Added a zoomable country map with typed data sources, percentage, bar, and pie overlays, and automatic mean aggregation when details would overlap. Country fills support GoodUI, heatmap, and custom color scales; selecting a country shades its direct neighbors. 8382407 Histograms and horizontal bars. Added multi-source Histograms with shared numeric intervals and an optional count table. Bar charts now accept orientation="horizontal" while keeping vertical as the default. 73deabc Scatter plots. Added a responsive, multi-source 2D chart with typed numeric or time X values, independent observations at repeated X positions, theme-aware marker colors, and an optional data table. 7db1c29 Sparklines. Added a compact trend component for metrics and Table cells. It uses typed chart data sources, theme-aware marker colors, optional endpoint and scale controls, and accessible descriptions. 8d85d04 Data visualizations. Added typed chart data sources, declarative axes, and responsive Line and Bar charts. Both can combine sources, use the theme-aware marker palette or a custom color array, and optionally switch to a data table. 6e813cc November 2, 2026 Detail lists and configuration summaries. The new good-detail-list aligns native label/value pairs for settings, metadata, and price breakdowns. NumberInput fills its available width by default, and AssistantPanel can use a soft, borderless surface. The VPS creation study demonstrates these compositions. 93b6154 Navigation matching. Sidebar routes can use activeMatch="exact" in their item configuration so an overview entry does not stay selected on sibling pages. 93b6154 Timeline sections. Use appearance="sections" and declarative <good-timeline-section> elements for long forms with state markers, a dashed rail, and section headings that stay at the top of the scrolling view. The VPS creation case study demonstrates the pattern. fdb9e51 Declarative Table cells. Add <ng-template goodTableCell="name" let-row> inside a Table to compose a page-specific cell directly in HTML. The Tables page demonstrates a server name with a status LED and details; the VPS case study also shows responsive columns and sends maintenance notices to the shell bell. f4e34f8 Responsive Table columns. Column definitions can set meta.visibleFrom to xs, sm, md, lg, or xl. The Table uses its own available width and restores hidden columns as space grows. The VPS creation and Tables examples demonstrate this. fb88828 Mobile Topbar branding. The drawer button now comes before the optional symbol or wordmark. Set [showMobileBrand]="false" to hide mobile Topbar branding without changing the sidebar. 360fd04 Form spacing. Paragraphs now leave spacing to their parent containers. Group uses a consistent 16 px content gap and offers spacing="tight" for clustered choices; the VPS creation example shows the resulting form rhythm. e6e2302 Assistant panel. Added a contextual companion surface with declarative sections, a mobile drawer or bottom dock, and an option to hide it on mobile. Fill-view headings keep the normal page inset, and InlineImage can show wide screenshots. f9c83ce Case studies. Grouped the Webmailer examples and added a VPS hoster study with a server list and creation flow. Both demonstrate GoodUI compositions with local sample data. f9c83ce Tabs. Tab panels no longer add a frame, surface, or inner padding around nested Cards and Tables. A subtle line after the content marks the end of the tab set. e681dde November 1, 2026 ActionBar and fill workspaces. Added grouped commands with priority-aware More overflow and projected search or filter tools. MainView can keep a toolbar above height-filling content; the Mail workspace example shows the composition. 021a93c Listbox density. Lists can remove their outer frame with [bordered]="false" and use compact for tighter rows. 021a93c Table behavior. Columns can be moved by mouse, touch, or keyboard by default; [reorderable]="false" keeps them fixed. tableStyle="compact" sets compact rows in HTML, and applications can emphasize rows from their data. 021a93c Resizable. Added a responsive two-pane workspace with adjustable split, four divider handles, independent pane scrolling, and mouse, touch, and keyboard controls. 6c95a06 Table row selection. Tables can opt in to single-row selection with a visible highlight, controlled selected ID, and a row-selected event. Cell controls keep their own actions. 6c95a06 Timeline. Added responsive process steps with simple, detailed, and illustrated views, optional start and end graphics, explicit progress and color controls, and declarative step markup. cadf327 Signature pad. Capture pen, touch, or mouse signatures as timed strokes and standalone SVG images, with built-in Clear and optional InkML export. 86e67dd Rich text editor tools. The optional features allowlist selects individual editing tools; leaving it out keeps the full toolbar. 2656edb Rich text editor. Added a formatted HTML editor with command-based undo and redo, links, images, tables, and an optional assistant pane. Table actions support touch, cell selection, header cells, and drag resizing of columns and rows. The Compose mail example shows a full-page editor. e2d6685 ColorPicker and ColorControls. Added a compact color selector with presets, optional custom colors, and detailed RGB, HSL, and hex editing. e2d6685 FontSelect. Added a font selector with previews that offers named fonts only when they are available in the current browser. e2d6685 Textarea. Added a multiline form control with three sizes, optional vertical resizing, readonly and disabled states, error styling, and Angular Forms support. The registration example now includes an optional profile introduction. bf49b93 RangeSlider. Added single-value and interval sliders with step constraints, optional bounds and tick labels, thumb icons, color choices, step buttons, and Angular Forms support. 875cf9f October 31, 2026 Fill layout for workspaces.
