Data visualizations Bar charts Compare values by category with the same data-source and axis contract as line charts. Pass one or more typed sources, declare the axes, and add one good-chart-bar per measure. Bars with the same X value sit beside each other. The chart owns its Card, legend, responsive plot, and optional data-table switch. Two series in GoodUI colors The first bars use GoodUI marker blue; the second use marker teal. The table icon in the Card header reveals the same numbers in a GoodUI Table. A custom palette and one-dimensional data Set [colors] to an array of marker names or CSS colors to replace the chart palette. Here violet stays theme-aware. With one numeric key and no xKey, row positions become the X values. Set color on an individual bar definition when just that series needs another color. Horizontal bars Set orientation="horizontal" when category labels need more room or a ranked comparison reads better from top to bottom. The source keys and declarative axes stay the same: X describes the categories in the data, Y describes their numeric values. GoodUI rotates their visual placement.
