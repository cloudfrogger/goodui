Data visualizations Histograms Turn individual numeric measurements into a distribution of counts. A Histogram groups raw values into adjacent intervals. It answers “How often did a value fall in this range?” rather than comparing named categories. Supply one numeric key per source; GoodUI chooses common bin boundaries for every series so their distributions are comparable. Compare two distributions Eight equal intervals cover 0–56 minutes. A value at an interval boundary enters the interval on its right; 56 enters the last interval. The table button shows the count for each interval and source. Sample values are illustrative. One source and a custom color Set [binCount] to an integer from 2 through 40. With no X bounds, GoodUI uses the smallest and largest valid values across all sources. [colors] replaces the marker palette; a series can override it with its own color.
