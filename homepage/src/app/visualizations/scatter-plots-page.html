Data visualizations Scatter plots See how two numeric measurements relate, with each source shown as its own series. Each row supplies one X and one Y value. Add one good-chart-scatter for each source. The plot keeps observations with the same X value separate, so repeated measurements stay visible. Axes, Card, palette, and data-table switch follow the other GoodUI charts. Compare two sources Blue and teal are the default marker colors. Hover a point to read its values; the table button shows every observation, including both points at 38 KB for Service A. Sample measurements are illustrative. Choose colors Set [colors] to marker names or CSS colors. An individual good-chart-scatter color="..." overrides the palette for that series. A time X axis is also possible when its key is a date or datetime.
