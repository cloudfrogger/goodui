Data visualizations Line charts Compare measured values across categories or time without writing chart CSS. Give the chart one or more typed data sources, define the axes, then add one line per measure. The card, legend, and responsive plot are part of good-line-chart. This sample uses illustrative monthly averages for Düsseldorf and Valletta. Two cities, one year The table icon in the Card header reveals the same values as a table; the chart icon returns to the plot. The switch is optional. Without a palette input, the lines use GoodUI's theme-aware marker and highlight colors. One-dimensional source A one-key source can still make a line. With a numeric X axis and no xKey, the chart uses row positions 1, 2, 3, and so on. Here [colors] replaces the default palette with an array containing the theme-aware violet marker. An individual good-chart-line color="teal" would override its assigned palette color.
