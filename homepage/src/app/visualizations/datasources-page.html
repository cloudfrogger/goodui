Data visualizations Data sources One typed data contract for every GoodUI visualization. Start with a source ID, describe every key once, then supply ordinary rows. A source can hold one, two, or three dimensions. The chart selects the keys it needs; extra keys stay available to other visualizations. Choose key types deliberately category accepts a string and preserves source order. number accepts a finite JavaScript number; integer accepts only whole numbers. date accepts a Date or an ISO day such as 2026-01-01. datetime accepts a Date or an ISO timestamp with a timezone, such as 2026-01-01T12:00:00Z. Null and invalid values are skipped; numeric strings are never silently converted. Keys may also have a readable label and unit. IDs and key names are stable references between the data source and a chart. For a one-dimensional line, omit xKey and use a numeric X axis; row positions become 1, 2, 3, and so on. Define the axes in the template Use one good-chart-axis position="x" and one with position="y". Choose type="category", number, or time to match the source key. Optional label, min, max, and ticks describe the visible scale. precision rounds numeric tick labels only; it never changes the measurements or table values. For dates, set groupBy="day", month, or year on the time axis. For Line and Bar charts, choose aggregate="mean", sum, min, max, count, first, or last when several rows fall in one bucket. They report duplicate buckets when aggregation is omitted. Scatter plots instead keep every observation, including repeated X values; set an aggregation there only when you explicitly want to combine them. Combine sources Pass multiple sources in [sources]. Each good-chart-line, good-chart-bar, or good-chart-scatter names its source and its X and Y keys. Line and Bar charts align shared categories; Scatter plots position each numeric or time X value independently. All three use GoodUI's theme-aware marker and highlight colors: blue, teal, violet, amber, rose, and lime. Set [colors] to your own array, or override one series with color. The Line chart guide lists the named color choices.
