Data visualizations Sparklines A small trend line for a metric or table cell, using the same typed data sources as larger charts. A Sparkline shows one numeric series without axes, labels, or a Card of its own. Give it a GoodChartDataSource and a numeric yKey. With no xKey, each row gets the next horizontal position. The endpoint dot makes the latest value easy to spot; the SVG describes the trend to screen readers. One compact metric
