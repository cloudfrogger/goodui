The good-notifications bell opens the notification inbox. Its badge counts unread messages, and the dialog shows messages published through GoodNotificationCenter together with optional items supplied by your application. Try it Add notification UsageThe items input accepts readonly GoodNotification[] and defaults to an empty array. open() and close() control the dialog. Escape and the Close button return focus to the bell. AppLayout already includes the notification host. For toasts without AppLayout, place exactly one good-notification-host near the application root. Register provideGoodUI() once to configure persistence.
