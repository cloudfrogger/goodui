Header menu Responsive header navigation with nested submenus, alongside your header actions. Responsive navigation Use good-header-menu for the navigation side of your topbar and good-header-actions for Search, Notifications, Theme toggle, and Avatar. Import GoodHeaderMenuComponent and pass your navigation items. The menu owns layout, opening, and keyboard behavior. Try Help → Support in this example. On mobile, open the menu with its grid icon. Parent items expand a level; only links navigate.
Header submenu good-header-submenu belongs to Header menu. Add children to a navigation item to create the next level; the menu composes it automatically. You do not need to place or position a separate submenu in your page. The first panel uses good-header-dropdown-menu and good-header-dropdown-item. A parent row opens good-header-submenu, which reuses those rows for further levels. Desktop panels flip toward available viewport space; mobile levels stack inside the popup or drawer. Use click, hover on desktop, or keyboard focus to open a parent. Escape closes the deepest open level and restores focus to its trigger; outside clicks close the menu. Parent buttons expose aria-expanded and aria-controls, and active links expose aria-current="page". Mobile behavior Set mobileMode="popup" on Header menu for its own icon and popup. hidden explicitly hides this menu on mobile; essential navigation then belongs in your declarative Sidebar. AppShell receives the Sidebar and AppHeader as children, without navigation-array inputs.
