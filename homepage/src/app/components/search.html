Try the search dialog Select the magnifier below. Search for Tables by label or pagination by description, then choose a result to navigate. Try an unmatched word to see the empty state. Search the three sample navigation links. Opening the dialog focuses the search field. Matching ignores letter case and checks both the label and description. An empty query shows all supplied links. Use Tab and Shift+Tab to move between the field, results, and Close button. Enter follows a focused result. Escape or Close dismisses the dialog and restores focus to its magnifier. Choosing a result closes the dialog and navigates through Angular Router. Use Search in your application Import GoodSearchComponent and supply GoodSearchItem records. Give each item a unique, stable ID, a visible label, and an Angular route. The description is optional. Configure Angular Router in your application providers. Supply the searchable links The items input accepts readonly GoodSearchItem[] and defaults to an empty array. Your application supplies the navigation index. Search filters that index locally as the query changes. When nothing matches, the dialog displays No results.
id
Unique key used to track each result.
label
Visible result title, included in matching.
description
Optional supporting text, also included in matching.
route
Destination passed to Angular Router when the result is selected.
open() / close()
Public methods used by the trigger and dialog controls.
 Connect the application shell The shell already includes Search in its main menu. Pass the same records through searchItems on good-app-layout, good-topbar, or good-main-menu. For the root shell from Layout → General, use this binding. A standalone good-main-menu also accepts [showSearch]="false" to hide its search action. The default is true. A visible search field in page content For a search field that stays visible above a list or card grid, use Input with type="search". Bind its value to your page's filtering logic. Place Search inside Main menu to compose your topbar actions.
