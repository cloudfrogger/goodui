The good-avatar-menu account control shows an avatar or initials and opens identity details, navigation links, nested actions, a Dark Mode switch, and an optional sign-out action. Try it UsageThe user input accepts GoodUser or null and defaults to null. The actions input accepts readonly GoodMenuAction[] and defaults to an empty array. GoodUser supports name, email, initials, avatarUrl, and badge. Actions support id, label, icon, route, action, children, detail, separatorBefore, and variant. Use children for expandable parents. The host application implements authentication and sign-out. Escape closes nested menus before the account panel and returns focus to the trigger. Outside clicks close the panel.
