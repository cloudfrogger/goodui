Bind an HTML string to [(value)]. Setting that signal loads existing HTML into the editor. GoodUI parses the markup, keeps supported formatting, and removes unsupported or unsafe elements and attributes. Edit the loaded content normally; the bound signal then contains the sanitized HTML. For text without markup, call getPlainText() on the rendered editor.
