# GoodUI Angular workspace

The standalone `@goodui/angular` library lives in `projects/goodui`. Tailwind CSS 4 compiles `projects/goodui/src/styles.css`; the Angular package and its compiled stylesheet are written to `dist/goodui`.

Build from the repository root with `npm run build:lib`, or from this directory with the same command. Public exports are listed in `projects/goodui/src/public-api.ts`. See the [integration guide](../README.md#how-to-use), [docs](../doc/docs/intro.md), and [demo](../demo1/).
