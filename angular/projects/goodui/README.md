# @goodui/angular

GoodUI's standalone Angular 21.2 component library. It exports the application shell, sidebar, topbar, nested navigation, main menu actions, main view, icons, data models, and `GoodThemeService`.

Build it from the repository root with `npm run build:lib`. The package is written to `angular/dist/goodui`; consumer applications import `@goodui/angular/styles.css` globally and configure Angular Router. See the [quick start](../../../README.md#how-to-use), [component docs](../../../doc/docs/intro.md), and [demo](../../../demo1/).
