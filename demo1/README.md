# GoodUI Demo 1

This standalone Angular application consumes the **built** `@goodui/angular` package through a local link. It demonstrates the desktop and mobile shell, nested sidebar navigation, the two-level Help → Support Forum topbar menu, search, notifications, dark mode settings, and the avatar menu.

From the repository root, run `npm run setup` and then `npm run start:demo`. Open `http://localhost:4200/`. After editing the library, rebuild it with `npm run build:lib`. If npm replaces the local link, restore it with `npm run link:demo`.
