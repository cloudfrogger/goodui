# Common mistakes

- **Guessing API names:** Open `ai/catalog/index.json`, then the selected detail file. Import the listed symbol from `@goodui/angular` and use the recorded selector and inputs.
- **Using an old catalog with another package version:** Compare the installed `@goodui/angular` version with the AI package. For a mismatch, fetch the exact matching release/tag or commit; never substitute `master` silently.
- **Treating `model()` as an ordinary input:** Its `nameChange` output is generated by Angular. For forms, prefer `formControlName` on components with `forms.controlValueAccessor: true`.
- **Adding a field without its required label:** The catalog marks required inputs. A hidden visual label still needs an accessible name.
- **Duplicating shell spacing or heading markup:** Use MainView and Group ownership as described in `layout.md`.
- **Assuming every Penpot shape is a public selector:** `penpot.kind` distinguishes component and internal part; absent mappings are marked in `missing`.
- **Assuming a successful TypeScript build proves usability:** Check keyboard focus, form errors, dark theme, and narrow screens in a browser.
