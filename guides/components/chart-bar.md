# Chart bar

`good-chart-bar` is a declarative configuration child of `good-bar-chart`; it does not render alone. Set `source` to a `GoodChartDataSource.id` and `yKey` to a declared `number` or `integer` key. Set `xKey` to a declared category, numeric, date, or datetime key compatible with the X axis. Omit `xKey` only with a numeric X axis to use row positions. Optional `label` sets the legend and table heading. Optional `color` overrides the chart's assigned palette color for this series.

See [Bar chart](bar-chart.md) for a complete example and [Chart data sources](chart-data.md) for types and conversions. Penpot publishes `goodui.chart-bar` with ID `1b6260d7-e591-805d-8008-e3535bb1b85d` on `42 Charts`.
