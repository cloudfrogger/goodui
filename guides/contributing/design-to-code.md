# From Penpot to Angular

The native GoodUI library snapshot belongs at `design/penpot/goodui.penpot`, but its export workflow is suspended while [Penpot issue #11554](https://github.com/penpot/penpot/issues/11554) remains unresolved. See [`design/penpot/README.md`](../../design/penpot/README.md) before resuming it. The token JSON below is a separate CSS generation input; live Penpot inspection and component mapping checks continue during the suspension. Check that the archive exists before claiming a snapshot is available.

## Workflow

1. Read `design.md` and the affected component guide. Inspect the GoodUI Penpot components and rendered homepage for visual questions.
2. Find the Penpot main component through MCP. Preserve its shape and library IDs; keep children as actual component instances.
3. Export and visually inspect desktop, mobile, and open states. Check the four default topbar actions individually; verify all three ThemeToggle icons and the optional Settings panel.
4. Keep the Penpot mapping and homepage API examples in sync.
5. Run `npm run build:homepage`. Check shell, menus, and drawer on desktop and mobile, including keyboard and screen reader behavior.

## Reusable component mapping

`design/component-map.json` is the machine-readable mapping for published Penpot UI components. Each `componentMappings` entry records the complete Penpot component name and stable library ID, Angular selector, internal-part owner where applicable, and design state. `variantManifests` points to the detailed axis and ID matrices without duplicating them. Most families map by the `goodui.<family>.<state>` → `good-<family>` rule. Internal visual parts, including DateInput's addon, day, and calendar families, map to their owning Angular component. The state suffix is represented by input data, projected content, or runtime state, not by a new selector. Brand artwork on `04 Logos` has no Angular selector and is documented separately above. Use this contract when importing GoodUI components into future Penpot project files and implementing those designs with `@cloudfrogger/goodui`. Run `npm run check:mapping` to validate the JSON against Angular selectors and variant manifests; compare its IDs with the live Penpot library through MCP when either side changes. The script itself does not connect to Penpot.
