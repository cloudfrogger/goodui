# GoodUI documentation

This Docusaurus project documents the design system, application shell, components, and integration examples for `@goodui/angular`.

The navbar includes an offline search index of the docs and a Components submenu. Search is available with `Ctrl+K` or `Cmd+K`. The navbar switches between transparent light and dark vector wordmarks; the favicon uses a vector GoodUI symbol. Source artwork remains in `../artwork/`, and the SVG assets used by Docusaurus are in `static/img/`. The wordmarks are exported from the matching editable Penpot components on `04 Logos`.

```bash
npm install
npm start
npm run build
```

The library source is in `../angular/`, the runnable example is in `../demo1/`, and the design contract is in `../design.md`.
